# 数据分析项目集 Data Analysis Portfolio

数据科学与大数据技术专业的数据分析项目合集，使用 Python + Pandas 完成数据清洗、分析与可视化。

## 技术栈

- **Python 3**：Pandas、NumPy（数据清洗、特征构造、聚合分析）
- **可视化**：Matplotlib、Seaborn、PyEcharts
- **数据库**：MySQL、HiveQL

## 项目列表

| # | 项目 | 简介 | 数据规模 | 核心技能 |
|---|---|---|---|---|
| 01 | [房地产市场洞察与价值评估](project-01-housing/) | 二手房价格影响因素分析 | 10.6 万条 | 数据清洗、特征构造、相关性分析 |
| 02 | [京东电商 3C 数据可视化分析](project-02-ecommerce/) | 手机 3C 商品多维度分析 | 2000 条 | 清洗、指标设计、可视化 |
| 03 | [城市空气质量数据可视化分析](project-03-air-quality/) | 6 城市空气质量时空分析 | 6 城市 × 全年 | 异常检测、聚合统计、趋势分析 |

## 快速开始

1. 安装依赖：`pip install pandas numpy matplotlib seaborn pyecharts`
2. 进入任意项目目录，用 Jupyter Notebook 打开对应的 `.ipynb` 文件
3. 数据文件位于各项目的 `data/` 目录
