# 房地产市场洞察与价值评估

## 项目简介
对约 10.6 万条二手房交易数据进行分析，探索房屋价格的核心影响因素。

## 数据说明
- 来源：练习数据集（`data/house_sales.csv`）
- 字段：城市、地址、面积、楼层、价格、省份、户型、朝向、单价、建成年份等

## 分析过程
1. **数据清洗**：剔除无用字段、缺失值与重复值处理、IQR 异常值过滤
2. **类型转换**：面积 / 价格 / 单价 / 建成年份等字段标准化
3. **特征构造**：区域、楼层类型、是否直辖市、卧室 / 客厅数量、楼龄、价格分段
4. **分析与可视化**：特征相关性热力图、价格分布、朝向与价格关系
