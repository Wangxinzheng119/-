# 京东电商手机 3C 数据可视化分析

## 项目简介
对 2000 条电商手机 3C 商品数据进行多维度分析，识别品牌价格定位与热销特征。

## 数据说明
- 来源：练习数据集（`data/电商数据_手机3C_模拟2000条.csv`）
- 字段：商品 ID、标题、品牌、类目、现价、原价、折扣率、评价数、好评率、店铺、是否自营等

## 分析维度
1. **价格**：各类目价格分布箱线图、品牌均价对比
2. **品牌**：热销榜品牌 / 单品 TOP20
3. **销量口碑**：好评率分布、价格 × 销量相关性（IQR 剔除异常后）
4. **类目**：商品数、均价、总评价量
