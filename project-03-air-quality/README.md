# 城市空气质量数据可视化分析

## 项目简介
对 6 个城市 2023 年逐日空气质量数据进行时空分析，比较城市间空气质量差异与季节规律。

## 数据说明
- 来源：练习数据集（`data/air_quality_2023_daily.csv`）
- 字段：城市、日期、月份、PM2.5、PM10、SO2、NO2、CO、O3、AQI、空气质量等级

## 分析过程
1. **数据清洗**：类型转换、缺失值检查、IQR 异常值检测
2. **描述性统计**：分城市 / 月份 / 等级的均值、最大最小值
3. **可视化**：各城市年均 AQI 对比、月度变化趋势、PM2.5 与 PM10 相关性、污染物相关系数矩阵、空气质量等级分布、季节变化规律
